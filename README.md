## Overview

NextAI is a commercial SaaS platform focused on AI-powered services, educational content, and business automation.

Built and maintained by Adam Jastrzębski and Łukasz Koszołko.

The project combines a modern React frontend with authentication, subscription management, payment processing, and backend services built on Supabase infrastructure.

This repository serves as a technical showcase of the technologies, integrations, and engineering solutions implemented during the development process.
